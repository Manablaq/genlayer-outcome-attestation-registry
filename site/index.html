Reusable Intelligent Contract Primitive

Consensus-backed attestations for claims builders can reuse.

OutcomeAttestationRegistry lets GenLayer applications request, resolve, cache, and consume structured attestations about external evidence without rebuilding the same adjudication machinery in every contract.

View Repository Contract Source Testing Guide

Why It Matters

Many GenLayer applications need to evaluate web data, API responses, documents, or natural-language criteria. A normal smart contract cannot do that directly, and a centralized backend becomes a trusted adjudicator.

This registry makes the adjudication result reusable. Escrows, bounties, prediction markets, DAO tools, reputation systems, agent marketplaces, and policy gates can all consume the same attestation interface.

Structured Requests

Each request records a subject, claim, evidence URI, criteria, expiry, and canonical fingerprint.

Independent Validation

Every validator fetches the registered evidence and reapplies immutable criteria before strict agreement.

Consumer Methods

Downstream builders can call verifier methods instead of parsing full attestation objects.

Architecture

One auditable resolver evaluates every evidence source. The registry writes only after strict agreement on every consequential field.

API

Method Purpose
request_attestation Create a request or return an existing fresh request or attestation for the same fingerprint.
resolve_attestation Generic AI/web resolver for semantic claims.
get_attestation Read the full stored attestation by request id.
get_latest_by_fingerprint Find the latest resolved attestation for a canonical claim fingerprint.
is_attested_true Verifier method for downstream contracts and frontends.
is_attested_false Verifier method for negative attestations.
is_fresh Check whether an attestation exists and has not expired.

Integration Pattern

Consumer contracts should depend on the verifier surface. They do not need to parse confidence, summaries, or evidence digests themselves unless their application needs deeper inspection. 

registry = OutcomeAttestationRegistry(registry_address)

if not registry.view().is_fresh(request_id):
    raise gl.vm.UserError("attestation expired")

if not registry.view().is_attested_true(request_id, u32(8000)):
    raise gl.vm.UserError("attestation not verified")
